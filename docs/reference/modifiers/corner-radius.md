# CornerRadius

Rounds the corners of a widget.

```luau
modifiers = {
    cornerRadius = { all = Units.Unit(12) }
}
```

## Properties

| Property | Type | Description |
|---|---|---|
| `all` | `Unit` | Radius applied to every corner. |
| `topLeft` | `Unit?` | Top-left radius override. |
| `topRight` | `Unit?` | Top-right radius override. |
| `bottomLeft` | `Unit?` | Bottom-left radius override. |
| `bottomRight` | `Unit?` | Bottom-right radius override. |
