# Padding

Adds inner padding to a widget.

```luau
modifiers = {
    padding = { all = Units.Unit(16) }
}
```

## Properties

| Property | Type | Description |
|---|---|---|
| `all` | `Unit` | Padding applied to every side. |
| `left` | `Unit?` | Left padding override. |
| `right` | `Unit?` | Right padding override. |
| `top` | `Unit?` | Top padding override. |
| `bottom` | `Unit?` | Bottom padding override. |
