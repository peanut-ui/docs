# TextSizeConstraint

Clamps a text widget's font size between a minimum and maximum.

```luau
modifiers = {
    textSizeConstraint = {
        min = 12,
        max = 32,
    }
}
```

## Properties

| Property | Type | Description |
|---|---|---|
| `min` | `number` | Minimum text size. |
| `max` | `number` | Maximum text size. |
